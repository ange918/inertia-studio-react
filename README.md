# INERTIA Studio — React + Vite

Reproduction du template Inertia (Lucas Gusso / Webflow) en React.

## Lancer le projet

```bash
npm install
npm run dev
```

Ouvre http://localhost:5173

## Sections

- Hero INERTIA + astronaute
- Marquee animé « WE CRAFT DIGITAL STORIES… »
- UNLEASH / HORIZON / LUMIX
- Grille projets
- Footer INERTIA STUDIO

Built with React, Vite and Framer Motion.
